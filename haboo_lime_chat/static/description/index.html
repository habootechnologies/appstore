Overview

Chatbot conversations that become CRM opportunities

LimeChat handles customer conversations on your website or social channels — but without an Odoo integration, those conversations exist only inside LimeChat. This module bridges the gap with a live webhook endpoint that captures every incoming chat as a structured Odoo record the moment it arrives.

Each Lime Chat record stores the customer's name, email, and phone alongside five flexible extension fields that map to any extra payload LimeChat sends. When a conversation shows sales potential, one button opens the Convert to Opportunity wizard — it finds existing partners and leads automatically, so your team creates a qualified opportunity in seconds.

Process

From chat to CRM opportunity in three steps

LimeChat fires a webhook — Odoo captures it — your team converts it. No manual data entry at any step.

1
LimeChat sends a POST

The platform fires a JSON payload to /webhook/haboo_lime_chat with partner info, up to 5 text fields, and a bearer token.

2
Token validated, record created

Token is checked against haboo_lime_chat.api.token in System Parameters. On success, a new Lime Chat record is created automatically.

3
Salesperson converts to opportunity

One click opens the wizard — auto-finds existing partners and leads, lets the salesperson create a new opportunity or link to an existing one.

Features

Everything the module gives you

Webhook Auto-Record Creation

The endpoint /webhook/haboo_lime_chat receives JSON, validates the token, and auto-creates a Lime Chat record — no manual entry required.

Five Flexible Extension Fields

field_one through field_five map to text_1–text_5 in the payload. No schema changes needed as the API extends.

Partner Auto-Detection

The wizard searches for an existing res.partner by email then by phone before prompting to create a new contact — fewer duplicates, faster conversion.

Convert to Opportunity Wizard

Choose to create a new opportunity or link to an existing one. Wizard pre-fills name, email, phone, and description; lets you set salesperson, team, and priority before creating the lead.

Token-Secured Endpoint

Every incoming request is validated against haboo_lime_chat.api.token in System Parameters. Mismatched tokens are rejected before any record is created.

Double-Conversion Guard

The is_converted flag prevents the same chat from producing two separate opportunities. The Convert button is blocked once a lead is already linked.
