Overview

Four Shopify entity types synced to Odoo automatically

This module connects Odoo to the Shopify Admin REST API using a stored access token and shop URL. It syncs four entity types on a configurable schedule: products (with shopify_product_id and paginated fetching via since_id), customers, orders, and abandoned checkouts.

Orders arrive with fulfillment_status, financial_status, and tracking numbers — so warehouse and finance teams have real-time Shopify data inside Odoo without a manual export step. Abandoned checkouts land in an abandoned.cart model with a computed price_subtotal field — so your team can spot high-value abandoned carts and reach out proactively.

Process

Connect once, sync four entity types automatically

1
Enter shop URL and access token

In General Settings, enter your Shopify shop URL and Admin API access token. Odoo stores both securely in res.config.settings fields — no code changes required.

2
Scheduler pulls all four types

Odoo's scheduled actions fetch products (paginated via since_id), customers, orders, and abandoned checkouts — creating or updating records with the Shopify IDs as keys.

3
Team acts on Shopify data in Odoo

Sales reps convert abandoned carts to CRM opportunities. Warehouse teams view fulfillment status. Finance teams see payment status. All without opening the Shopify dashboard.

Features

Everything the module gives you

Paginated Product Sync

Products are fetched using since_id pagination — the last synced Shopify product ID is remembered so each sync only fetches newer products, handling large catalogs efficiently without duplication.

Customer Sync

Shopify customers are pulled and matched or created as res.partner records in Odoo — with Shopify customer ID, email, name, and order count. Existing partners are updated, not duplicated.

Order Sync with Fulfillment

Shopify orders arrive in Odoo with order ID, name, fulfillment_status, financial_status, email, phone, total price, and tracking number — giving warehouse and finance teams a complete picture without Shopify access.

Abandoned Cart with Computed Total

The abandoned.cart model stores Shopify's abandoned checkout data. A computed price_subtotal field surfaces the cart value — enabling priority sorting of recovery outreach by cart size.

CRM Opportunity Conversion

Both customers and abandoned carts can be converted to CRM opportunities — with cart value, customer details, and Shopify checkout URL pre-filled. Sales reps pick up from the lead without any manual data entry.

Config in General Settings

Shop URL and access token are stored in res.config.settings — set once in General Settings and available to all sync methods. No hard-coded credentials or server restarts required.

Shopify Product ID Tracking

Every synced product carries a shopify_product_id field on the Odoo product template — so records are matched precisely on re-sync and never duplicated, even after product edits in Shopify.

Order Line Items

Each order record stores its line items — product name, quantity, price — inside Odoo. Finance and ops teams can see what was ordered without toggling to the Shopify order page.
