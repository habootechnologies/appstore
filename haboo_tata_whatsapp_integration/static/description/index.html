Overview

Two Tata WhatsApp lines managed from one Odoo install

The Tata Communications WhatsApp Business API lets enterprises send and receive WhatsApp messages at scale. This module brings that capability inside Odoo with a dual-line architecture — Line 1 and Line 2 each have their own session model, state machine (New / Running / Close), and agent assignment, so different teams or use cases can operate independently on separate numbers.

Agents dispatch approved WhatsApp templates (retail product inquiry and Shopify abandoned cart) directly from session records. A dedicated SLA Session model links a Line 1 and Line 2 session together for cross-line tracking. All sessions link to CRM opportunities, keeping WhatsApp conversations part of your sales pipeline.

Process

Session opens, agent dispatches, SLA tracked

1
Session created on Line 1 or 2

An inbound WhatsApp on either line creates a session record with customer name, number, agent assignment, state, and CRM opportunity link — ready for the assigned agent.

2
Agent sends template message

From the session form, agents dispatch a retail product inquiry or abandoned cart WhatsApp template with one click — no separate Tata dashboard needed.

3
SLA record closes the loop

The SLA session model links both lines for a single conversation — enabling accurate response time reporting across the full customer journey regardless of which line handled each leg.

Features

Everything the module gives you

Dual-Line Session Models

Line 1 (tata.whatsapp.session) and Line 2 (tata.whatsapp.session.2) are independent models — each with its own session list, form, state machine, and agent field.

Session State Machine

Three states — New, Running, Close — on both lines. The is_close_visible flag controls when the Close button shows, preventing premature session closure.

Template Message Dispatch

Two outbound template methods: retail_product_inquiry for standard enquiries and abandoned_cart_enquiry_ for Shopify cart recovery — both sent via the Tata API from the session form.

Send Message + Media

Each session has a send_message field and product image/file name fields — so agents can share product visuals and documents directly from the session record.

SLA Session Model

sla.whatsapp.session links a Line 1 session and a Line 2 session in a single SLA record — enabling response-time reporting across the complete conversation regardless of which line handled each leg.

Agent + CRM Assignment

Each session carries an agent_user_id and opportunity_id — so every WhatsApp conversation is owned by a specific agent and tied to the corresponding CRM lead.

Remarks & General Conversation

The remarks and is_gen_con fields let agents annotate sessions with context flags and free-text notes visible to the whole team.
