Overview

Facebook Messenger and Instagram DMs unified in Odoo

Meta's Graph API is the official way to build messaging integrations for Facebook Messenger and Instagram Direct. This module connects Odoo to that API through the messenger.provider model — which handles authentication state, Graph API URL, token, account ID, and connection validation via a live /me endpoint check.

Separate history models for Facebook Messenger and Instagram each support image, document, audio, and video media types — keeping conversation history rich and complete. The Messenger Template model stores reusable outbound templates with body HTML, language, state (draft/imported/added), and template component definitions. A verify token generator handles the Meta webhook subscription handshake without any manual code.

Process

Connect, receive, and reply in three steps

1
Configure Graph API provider

Create a Messenger Provider record with your Graph API URL, access token, and account ID. Generate the verify token and register it as your Meta webhook. Click Reload Status to validate the live connection.

2
Messages arrive and are stored

Inbound Messenger and Instagram messages are stored in their respective history models with full media type support — text, image, document, audio, and video all captured as separate records.

3
Team responds using templates

Agents select a saved Messenger Template and send from the history record — outbound messages are routed back through the Graph API to the correct platform and recipient.

Features

Everything the module gives you

Graph API Provider

messenger.provider stores Graph API URL, access token, account ID, and authentication state. Live connection validated by calling the /me endpoint directly from Odoo.

Facebook Messenger History

Dedicated message history model for Facebook Messenger with support for all rich media types: image, document, audio, and video — each stored with sender details and timestamp.

Instagram DM History

Parallel history model for Instagram Direct Messages — same rich media type structure as Messenger, keeping both platforms' history cleanly separated and individually searchable.

Message Template Model

messenger.template stores reusable outbound templates with name, provider, model binding, body HTML, language, state (draft/imported/added), and component definitions.

Webhook Verify Token

GenerateMessengerVerifyToken creates the verification token needed for the Meta webhook subscription handshake — no manual token generation or config file editing required.

Provider State Tracking

The provider model tracks graph_api_authenticated state and authentication type — so Odoo always shows whether the Meta connection is live and valid.

Username & Account ID

The provider stores the Meta account's username and account_id — so messages are always routed to and from the correct verified business account.

Template Component Definitions

The template_components_ids One2many on each template stores header, body, and footer component definitions — enabling structured Meta template messages with approved layouts.
