Overview

Google Place reviews tracked inside your CRM

Without an integration, monitoring Google Business reviews means logging into Google Maps manually, copying data, and hoping nothing falls through the cracks. This module connects Odoo to Google's Business Profile API via OAuth 2.0 — once authorised, reviews flow in automatically on a configured schedule.

The Google Review model inherits mail.thread, so your team can add notes, tag colleagues, and discuss responses directly on each review record. The scheduler record limit is configurable from 50 to 500 reviews per run — so large businesses with high review volumes stay in control of data volume.

Process

Authorise once, reviews sync forever

1
Connect via OAuth 2.0

Enter your Google Client ID, Client Secret, and Redirect URI in Settings. Click Connect Google to complete the OAuth flow. Tokens are stored and auto-refreshed.

2
Scheduler pulls reviews

A scheduled action calls Get All Reviews automatically. Odoo fetches up to the configured limit (50–500) of Google Place reviews and creates records sorted by date.

3
Team reviews and responds

Each review has a chatter (via mail.thread) — teams log notes, discuss responses, and track resolution without leaving the record.

Features

Everything the module gives you

Google OAuth 2.0 Flow

Full OAuth 2.0 connection via /google/oauth controller. Access token and refresh token are stored and automatically refreshed when expired.

Scheduled Auto-Pull

Odoo's scheduler calls Get All Reviews automatically. The configurable record limit (50–500) prevents runaway imports for high-volume businesses.

Google Review Model

The google.review model stores reviewer name, rating, review text, and timestamp. Default ordering by review_updated_time desc keeps newest reviews at the top.

mail.thread Integration

Google Review inherits mail.thread — so teams can log internal notes, discuss reply strategies, and follow individual reviews without leaving Odoo.

Settings Integration

Client ID, Client Secret, Redirect URI, and the scheduler record limit are all configurable from Odoo's General Settings panel — no code changes needed after initial setup.

Token Expiry Handling

The google_token_expiry_seconds field tracks when the access token expires. The module uses the stored refresh token to obtain a new access token automatically before each scheduled pull.
