Overview

Wondersoft POS synced to Odoo — products, customers, and orders

Wondersoft is a widely used retail POS and ERP solution in India. This module connects Odoo to the Wondersoft eShopaID XML API using a wondersoft.credential record that stores the API token and base URL. Authentication is handled on every sync automatically — no manual re-login required.

Products are fetched and synced as Odoo product templates — paginated by page_number to handle large catalogs. Customers land in Odoo as partners with GSTIN, wondersoft_id, and modified_date — supporting incremental updates and GST compliance. Sale orders are fetched per store_code, so multi-store Wondersoft installations sync each store's sales into Odoo independently.

Process

Token in, data synced, team works in Odoo

1
Create credential record

Create a wondersoft.credential record with the eShopaID API token and base URL. Odoo uses these credentials on every scheduled sync to authenticate with the Wondersoft XML API.

2
Scheduler pages through data

Products and customers are fetched page by page using page_number. Orders are fetched per store_code. Each record is created or updated in Odoo using the Wondersoft ID as the unique key.

3
Team uses Wondersoft data in Odoo

Finance teams see GSTIN on customer records. Ops teams see orders per store. Product managers compare Wondersoft catalog with Odoo inventory — all from a single Odoo interface without Wondersoft access.

Features

Everything the module gives you

Credential Model

wondersoft.credential stores the eShopaID API token and base URL — used automatically by all sync methods. No need to pass credentials manually or restart the server after changes.

Paginated Product Sync

Products are fetched using page_number pagination — the sync loops through all pages until the API returns an empty result, ensuring the complete Wondersoft catalog lands in Odoo.

GSTIN Customer Sync

Customer records carry gstin, wondersoft_id, and modified_date — supporting Indian GST invoicing requirements and incremental re-sync based on the last modification timestamp.

Multi-Store Sale Order Sync

Orders are fetched per store_code — Wondersoft installations with multiple retail stores each sync their own order stream into Odoo independently, keeping per-store sales data clean and separate.

Wondersoft ID as Sync Key

Every synced record — product, customer, or order — uses the Wondersoft ID as its unique key. Subsequent syncs update existing records rather than creating duplicates, keeping Odoo data clean.

Scheduled Automated Sync

All three sync types (products, customers, orders) run on Odoo scheduled actions — frequency configurable from the Odoo scheduler. No manual trigger or Wondersoft portal access needed for day-to-day operation.
