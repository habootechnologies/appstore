Overview

WhatsApp Business messaging, without leaving your CRM

Gupshup provides one of the most widely used WhatsApp Business API gateways, but most teams still end up managing conversations in a separate portal. This module wires Odoo directly to that API through a gupshup.message.history model, so every inbound and outbound WhatsApp message is a queryable Odoo record.

A Settings screen under Sales/CRM configuration holds your Gupshup credentials, and a reply wizard lets any team member respond to an inbound message from directly inside its history record - no separate Gupshup portal login required.

Process

From a WhatsApp message to a CRM conversation

1
Connect your Gupshup account

Enter your Gupshup API key and WhatsApp Business number once under Settings > Sales/CRM configuration.

2
Messages sync into history

Every inbound and outbound WhatsApp message is stored in the gupshup.message.history model, timestamped and linked to the sender.

3
Reply without leaving Odoo

Use the built-in reply wizard directly from any message history record to respond, with the message routed back through Gupshup automatically.
