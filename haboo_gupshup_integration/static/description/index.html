Overview

WhatsApp conversations living in your CRM

The Gupshup WhatsApp Business API lets businesses send and receive WhatsApp messages at scale — but without an Odoo integration, those conversations stay siloed inside Gupshup's dashboard. This module bridges that gap with two webhook endpoints that pull every inbound message into Odoo as a structured record the moment it arrives.

Each WhatsApp Message record stores sender name, number, WhatsApp number, message content, image URL, message type, timestamp, and auto-linked Odoo partner. Your team can reply through the Send Reply wizard, trigger opt-in for new numbers, and let the delivery receipt handler keep status up to date automatically.

Process

Receive, store, and reply in three steps

Gupshup pushes the message — Odoo stores it and matches the contact — your team replies from the record. No tab-switching required.

1
Gupshup POSTs to Odoo

An incoming WhatsApp message triggers a POST to /whatsapp/messages carrying sender name, number, WA number, message type, and content.

2
Record created, partner matched

Odoo stores the message as a WhatsApp Message record and automatically links it to an existing res.partner by mobile or phone number.

3
Team replies from Odoo

The Send Reply wizard posts the reply back through the Gupshup API. Delivery status is tracked via the separate DLR endpoint automatically.

Features

Everything the module gives you

Inbound Message Webhook

Endpoint at /whatsapp/messages receives both text and image messages from Gupshup and creates history records automatically — no CSRF, no auth cookie required.

Delivery Receipt Handler

A dedicated /whatsapp/dlr endpoint captures Gupshup DLR callbacks and updates the delivery status on the matching message record in real time.

Message History Model

Each gupshup.whatsapp.messages record stores sender name, sender number, WA number, message text, image URL, message type, message ID, and date — fully searchable from Odoo.

Reply Wizard

The Send Reply button on any message record opens a wizard that posts the reply directly through the Gupshup API using SENDMESSAGE with HSM template support.

Auto-Partner Linking

On record creation, the module searches res.partner by mobile and phone fields and assigns the matching contact — keeping WhatsApp history tied to the right customer.

WhatsApp Opt-In

The Opt In button on any message record triggers a Gupshup OPT_IN API call for that sender number — required before sending outbound templates to new contacts.
