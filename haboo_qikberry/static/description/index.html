Overview

Qikberry and Odoo, kept in sync automatically

Running Qikberry alongside Odoo usually means someone manually re-keys data between the two. This module connects them directly, exchanging business data and automating the workflows that depend on it, with every message and record captured through a dedicated Qikberry message model.

A CRM opportunity conversion wizard lets your team turn any Qikberry-sourced interaction into a tracked deal, and a dedicated security group keeps that data visible to only the right users.
