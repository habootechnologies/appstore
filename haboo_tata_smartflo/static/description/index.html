Overview

SmartFlo call history, notes, and follow-ups — all in Odoo

Tata SmartFlo is an enterprise cloud telephony platform. Without an Odoo integration, call history lives in SmartFlo's portal while CRM data lives in Odoo — two systems your team must check separately. This module bridges that gap by pulling CDR records into a dedicated cdr.history model that carries call direction, status (missed/answered), recording URL, duration, region, department, agent name, client number, and agent number.

Call transcripts and remark fields let agents capture context right on the CDR record. Notes entered in Odoo can be pushed back to SmartFlo with one action. Missed calls automatically trigger a WhatsApp follow-up template — so no customer goes uncontacted. Every CDR can be linked to a CRM lead via the cdr_ids field on crm.lead.

Process

Pull, annotate, follow up — in three steps

1
Scheduler pulls CDR

Odoo calls _update_cdr_history_data on a schedule. SmartFlo returns CDR JSON; Odoo creates or updates records with call direction, status, duration, recording URL, and computed agent/client name fields.

2
Agent adds notes in Odoo

Agents type notes on the CDR record in Odoo. Clicking Update Notes pushes those notes back to SmartFlo via the API — keeping both systems in sync.

3
Missed calls get WhatsApp

For each missed call, auto_whatsapp_followup fires automatically — sending a WhatsApp follow-up template to the client number so no unanswered call goes unaddressed.

Features

Everything the module gives you

Scheduled CDR Sync

_update_cdr_history_data fetches from the SmartFlo CDR access URL on schedule. Records are created on first import and updated on subsequent pulls using the SmartFlo log ID as a unique key.

Full Call Metadata

Each cdr.history record stores: direction (inbound/outbound), status (missed/answered), recording URL, date, duration, region, department, agent name, agent number, and client number — plus computed client_id and agent_name_id.

Two-Way Note Sync

The Update Notes action on any CDR record posts the agent's notes back to SmartFlo via the note update URL — so annotations made in Odoo are reflected in SmartFlo's system of record.

Missed-Call WhatsApp Follow-Up

auto_whatsapp_followup fires for every missed call — sending a WhatsApp template to the client's number automatically so no unanswered inbound call goes without a response.

Transcript & Transcription

call_transcript and transcription_text fields store the AI-generated transcript. general_conversation and remark capture agent summaries.

CRM Lead Linkage

A cdr_ids Many2many field on crm.lead links multiple CDR records to a single opportunity — showing the complete call history of a customer within their CRM lead.

SLA Boo Flag

The sla_boo boolean flags calls that breached SLA — enabling quick filtered views to surface the records that need immediate management attention.

Config in Settings

The SmartFlo CDR access URL, note update URL, and API access token are all set from General Settings via res.config.settings — no hard-coded credentials.
